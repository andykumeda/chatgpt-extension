# Chrome Web Store listing draft

Name: Local Codex Side Panel

Short description: Chat with your local Codex setup beside a webpage, with automatic page context and a model picker.

Local Codex opens a chat in Chrome's side panel and connects to Codex through a separate Mac companion app. Choose a model and reasoning effort from the models available to your Codex account, set a workspace, and resume chats saved on your Mac.

The current page's URL, title, visible text and selected text are attached automatically when you send a message. Chrome site permission is required. Page context is sent through your local Codex setup to its configured model provider. Review the page preview before sending sensitive content.

Workspace edits and live browser access are optional per-message permissions and reset after each send. Browser click, fill and navigation actions also require individual confirmation. Voice input is not included.

Requires macOS 13.5 or later, Local Codex.app, and an authenticated Codex installation. Model access depends on your Codex account and configuration. Local Codex is an independent project and is not affiliated with or endorsed by OpenAI. Installation links and a public privacy-policy URL must be added before submission.

- Review final privacy disclosures against the exact submitted build. This draft is not a completed store submission.
